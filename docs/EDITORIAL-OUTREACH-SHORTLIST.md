## Important limits

- Bot API getChat checks resolve public channels and return their current counts/descriptions, but did not expose a property that tells whether channel Direct Messages are enabled.
- The Bot API is_direct_messages property identifies a Direct Messages chat itself once resolved; querying a parent channel username does not prove that its DM topic is enabled. See https://core.telegram.org/bots/api and https://core.telegram.org/bots/features.
- Verify the Message / Direct Messages entry point and Suggested Post option in a normal Telegram client. If absent, do not send promotional DMs.
- Public advertising contacts do not prove free placement. No messages, emails, or Suggested Posts have been sent to any listed channel.

## Manual route

Check @gen_m, @mendeleevshina and @slezisatoshi first. If a channel accepts free Suggested Posts, send one useful, non-promotional story with source links using docs/PROMOTION-PACK.md. The post must be useful even to a reader who never subscribes to CryptoPing RU. Record acceptance, rejection, published URL and downstream joins before approaching another channel.
